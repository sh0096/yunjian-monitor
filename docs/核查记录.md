2026-10-15 已使用一个授权账户实测设备列表、收益明细与状态查询。饭团云监工后台的具体实现未知；本项目是独立实现，不能据此断言其内部使用相同方案。本记录不包含授权账户的凭据或设备标识。

本次接入失败的具体原因是官方 `feed_id` 返回超出 JavaScript 安全整数范围的 JSON 数字，旧解析器只接受字符串。现在使用 Node 24 JSON reviver 的原始数字 token，避免 ID 被舍入，并兼容字符串形式的 result；已加入回归检查。

## 有源码依据的历史接口

设备网关共同前缀 `https://gw.smart.jd.com/f/service/`。请求包含历史客户端平台参数、`tgt`、`accesskey`、`appkey`、`Authorization`。**仅把 TGT 填进收益请求头并不能替代设备网关签名。**

| 用途 | 请求 | 响应证据 |
|---|---|---|
| 设备列表 | POST `listAllUserDevices`，历史客户端属性 JSON | `status=0`，`result[].list[]`，`feed_id/device_id/device_name/status` |
| 运行状态 | POST `controlDevice`，`feed_id` 与 `SetParams` 命令 `get_router_status_detail` | `result.streams[].current_value.data.upload/download/cpu/mem`；部分层为 JSON 字符串 |
| 积分明细 | GET `https://router-app-api.jdcloud.com/v1/regions/cn-north-1/todayPointDetail?sortField=today_point&sortDirection=DESC&currentPage=1&pageSize=15`，头 `wskey` | `code=200`，`result.pointInfos[].mac/todayPointIncome/allPointIncome`，`pageInfo.currentPage/totalPage/totalRecord` |

关键原始来源：[网关和积分代码](https://github.com/myleo1/JDC-Monitor/blob/351c25b893a81e50c4254d4be07af816e3589858/service/service.go)、[签名代码](https://github.com/myleo1/JDC-Monitor/blob/351c25b893a81e50c4254d4be07af816e3589858/service/cryptokit/crypto.go)、[分页实现](https://github.com/aaaaawhf/jdc-monitor-api/blob/39290222965b1fcedf074f6a09470f4a123b08cd/src/main/java/com/g1335333249/jdc/monitor/api/service/JdcService.java)。

不带任何用户凭据对历史 `todayPointDetail` 和 `todayPointIncome` 地址各做了一次 GET，均返回 HTTP 403，错误包含 `HTTP_FORBIDDEN` / `businessCode=2010`。这只证实服务有响应并拒绝匿名请求；**不是登录成功、不是接口完整有效、不是已知 TGT 过期码。** 本项目未将 2010 写成过期判据。

## TGT / WSKEY 生命周期

JDC-Monitor README 和 Java 后端把同一个值分别放在 `tgt`、`wskey` 头。本次授权账户也已验证同一值可用于这两类请求；网页仍允许提供独立 WSKEY。这不能推导出所有账户、客户端或未来版本均相同。

没有发现官方公开的发行时刻、固定 TTL、刷新令牌或自动续期协议。不能因名字 TGT 就直接套用通用 CAS / Kerberos 生命周期。官方 App 的重新登录、退出、风控等可能影响登录态，但不对失效时机作确定承诺。

当前实现：凭据的 `expiresAt` 不伪造；平台明确 HTTP 401 后暂停，其他鉴权/权限拒绝分开展示；凭据更新后重新校验。后台不保存用户账号密码，不模拟未查证的短信或密码登录。

## 实时含义与单位

本项目定时查询状态，默认约每 5 秒一次；网页约每 5 秒同步服务端最新值。设备列表缓存约 60 秒；收益在北京时间 00:00–02:00 每 10 分钟、其他时段每小时确认，跨日或设备变化时重新查询。请求按账户加锁，鉴权、权限和限流错误进入暂停状态。最近两小时保留逐次采样，长时曲线用每分钟平均值和峰值；离线与缺失值不当作零速率，中断期间不补造记录。

2021 网页采用 `upload / 8000`，2025 fork 采用 `upload / 10` 后标为 KB/s；它们的换算互相冲突，不能单凭开源示例定单位。本次进一步静态检查了官方客户端，现已移除手动换算配置。

### 官方客户端单位核查

来源为京东云官方[下载页](https://jdcwifi.jdcloud.com/app/jdcwifi/download/download.html)及其 [download.js](https://jdcwifi.jdcloud.com/app/jdcwifi/js/download.js) 指向的 [Android 安装包](https://download.jr.jd.com/downapp/cpp-guard-v-7825a61cfb-20260125205331.apk)。仅下载并静态读取所需 ZIP 条目，没有安装或运行该 App，也没有把用户凭据交给它。

Manifest 标识为 `com.jdcloud.mt.smartrouter`，版本 `4.13.3`，versionCode `109`。已校验读取的 `classes5.dex` 与 ZIP 中央目录 CRC 一致，其 SHA-256 为 `bc1fc5581e0d112921c42d77f570e8d395df233925497af139655a49d0463337`。

单位依据来自同一客户端中的调用链：

- `ApiIot.Companion.requestRouterDetail` 包含 `get_router_status_detail`。
- `HomeViewModel` 的状态回调读取 `RouterStatusDetail.upload/download`，经 `t0.c.u` 乘 1024 后放入 `WanUplinkRate/WanDownlinkRate`。
- 首页 `ItemPagerUIState.Companion.convertToRouterUIState` 将这些 bit/s 数值交给 `t0.c.x`：除 8 后除 1024 得到 KB/s，达到 1024 KB/s 后继续除 1024 显示 MB/s，再按同样方式进位。
- 太乙详情页 `RouterDetailTaiyiActivity` 的网络适配器将原始上行、下行交给同一格式化函数的另一输入类型；原始值除 8 得到 KB/s。两条路径的显示结果一致。

因此本项目内部将接口原值乘 1024 存为 bit/s，前端按上述字节速率规则自动进位。例：原值 8192 → 1 MB/s；原值 8000 → 1000 KB/s。界面沿用官方的 KB/s、MB/s 标签，实际进位基数是 1024。没有将该接口误解释成 100 字节/秒，也没有使用冲突示例中的 /10 换算。

官方瞬时速率会变化，本网页默认约每 5 秒采集一次，与 App 非同一时刻的数值可能不同。核查结果覆盖该客户端的上述接口路径，未来协议变化应重新验证。

## 凭据边界

浏览器仅短暂持有用户当次输入，提交/关闭后清空；不写 localStorage、sessionStorage、URL、CSV、服务日志。服务端加密密钥独立于数据库，AES-GCM 关联账户 ID；Cookie 只保存本系统随机会话，不保存京东凭据。SQL 使用绑定参数，外部请求地址固定且不跟随重定向。

公开仓库只包含源码、示例配置、生成数据的测试和演示截图。HTTPS 入口与部署参数均需由部署者配置，不包含任何真实运行实例的地址、数据库或登录信息。
